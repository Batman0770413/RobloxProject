الفكرة الأساسية للماب
الماب يتكون من 3 أجزاء رئيسية:

اللوبي
مكان تجمع اللاعبين.
بوابات أو أزرار للدخول إلى غرف البناء.
قائمة اختيار: بناء جديد، مشاريعي، تجربة مشروع، دخول ساحة اللعب.
غرفة البناء الخاصة
لكل لاعب غرفة منفصلة.
اللاعب يبني فيها روبوت، طائرة، سيارة، صاروخ، آلة، مبنى أو أي اختراع.
لا يستطيع اللاعب تعديل غرف اللاعبين الآخرين.
الغرفة لها حدود تمنع خروج البناء منها.
يوجد حفظ تلقائي للمشروع.
ساحة التجربة
عالم عادي أو ساحة كبيرة يختبر فيها اللاعب البناء الخاص به.
البناء ينتقل إلى الساحة كنسخة تجريبية، وليس النسخة الأصلية.
إذا انفجر الصاروخ أو تحطمت الطائرة، لا يتضرر مشروع اللاعب الأصلي داخل غرفته.
يمكن وضع حدود للساحة حتى لا يخرج منها أي شيء.
طريقة اللعب المقترحة
يمر اللاعب بهذه المراحل:

يدخل غرفة البناء.

تظهر علامة صح على المشروع.
يضغط بدء اللعب أو نشر المشروع حسب النظام الذي تختاره.

الفكرة النهائية تكون: اللاعب لا يكتفي ببناء شكل جميل، بل يصنع شيئاً له منطق وسلوك خاص به. ممكن لاعب يبني روبوتاً، لاعب آخر يبني طائرة، لاعب ثالث يبني لعبة صغيرة داخل مشروعه، ولاعب محترف يصمم واجهة تحكم كاملة.

النقطة المهمة: اجعلها منصة بناء وبرمجة داخل Roblox، وليس Roblox Studio كاملاً؛ لأن تشغيل كود Lua حر من اللاعبين خطر وغير مناسب. لكن تستطيع إعطاء اللاعبين حرية كبيرة جداً باستخدام لغة برمجة خاصة، بلوكات، إحداثيات، أحداث، GUI، ومكونات تتحقق منها السيرفرات.

بس مشكله لازم يبرمجون في لغه الكل يفهمها و يعرفها  يعني اذا سوينه لغه جديده محد راح يفهمها و لا يعرف يتعلمها ولا انا هههه 

هههه إي صحيح، إذا سوّينا لغة جديدة راح تصير مشكلة: اللاعب لازم يتعلم لغة الماب قبل ما يبدأ يبني. الحل الأفضل هو استخدام Luau، وهي لغة Roblox نفسها وقريبة جداً من Lua، ومعروفة عند المبرمجين.

لكن نستخدمها بطريقة آمنة ومحدودة، يعني اللاعب يكتب كود يشبه كود Roblox الحقيقي، لكن ما نسمح له يشغل أي أمر خطر.

مثال على كود اللاعب
lua


local rocket = project:GetPart("Rocket")
local launchButton = project:GetButton("LaunchButton")

launchButton.MouseButton1Down:Connect(function()
    rocket:MoveTo(Vector3.new(0, 20, 0))
    rocket:MoveForward(100)
end)
أو كود روبوت:

lua


local robot = project:GetPart("Robot")

robot.Touched:Connect(function(hit)
    if hit.Name == "Enemy" then
        robot:MoveForward(10)
    end
end)
أو تحكم بالكيبورد:

lua


Input.KeyDown:Connect(function(key)

الخلاصة
أفضل اختيار لمشروعك هو:

اللغة: Luau
الواجهة: محرر كود يشبه Roblox Studio
للمبتدئين: بلوكات وأكواد جاهزة
للمحترفين: كتابة Luau مباشرة
للتعليم: تحويل البلوكات إلى كود والعكس

بهذا الشكل اللاعب يتعلم لغة حقيقية ومعروفة، ويقدر يستخدم خبرته لاحقاً في Roblox Studio، وفي نفس الوقت ما يقدر يخرب الماب أو يحصل على صلاحيات خطيرة.

طيب اذا هو راد يستخدم كود جاهز يعني ذكاء اصطناعي مثلك هو يكتبه لك اريد لغه الكل يعرفها و حتى ذكاء اصطناعي عشوائي يعرفها و يفهم هذا الماب يستخدم هيج لغه

إي، بهذا الشرط أفضل اختيار هو Luau، لأن Roblox Studio نفسه يستخدمها، ومعظم نماذج الذكاء الاصطناعي تفهمها وتقدر تكتب بها كود للماب.

لكن حتى الذكاء الاصطناعي يعرف كيف يتعامل مع نظامك، تحتاج تسوي API موحدة وواضحة لمابك. يعني تستخدم Luau كلغة أساسية، وتوثّق الأوامر الخاصة بالماب بطريقة مفهومة.

مثلاً بدل ما تخلي الذكاء الاصطناعي يخمّن أسماء الأوامر، تعطيه هذه القواعد:

Project:GetButton("LaunchButton") يبحث عن زر.
button.Clicked يعني عند الضغط على الزر.
rocket:MoveTo(...) ينقل الصاروخ إلى إحداثيات معينة.
rocket:MoveForward(100) يحركه للأمام.

طيب عجبني كلش فكره الحين لاعب عنده تحكم كامل بناء و تجربه و ادوات تحكم و ادوات بناء و تلوين و برمجيات متنوعه و تسميات و لصق الاجزاء مع بعضها و توجيهات و كلشيء... انت اشرح شنو الماب هذا و كيف الاعب يبرمج كل بلوكه و مثل يضع ملف برمجي على كل بلوكه و كيف يعدل على كودات مثل عنده مجلد برمجي يخص روبوت و لوحه تعرض جميع مشاريعه و إستعاده مشاريعه القديمه و جديده و حفظ مشاريع و حذف و نسخ و غيرها  بس الإختبار داخل مصنع مالته و الإنطلاق في ساحه  تصير و 6 مصانع لان ماب يستوعب 6 لاعبين فقط و يبنون داخل مصانعهم و ينطلقون بعد ضغط زر انا جاهز و ينطلق هو و روبوته او حيوانه ويقدر من يبدي اللعب هو يكون داخل جهاز مالته لو داخل روبوت لو فوق حيوانه الاليف هو روبوت او ايشيء بعد انت تعرف

فكرتك صارت الآن ماب كامل اسمه مثلاً Roblox Engineering Sandbox: ستة لاعبين يدخلون إلى ستة مصانع منفصلة، وكل لاعب يمتلك مختبراً خاصاً به يبني داخله أي آلة أو روبوت أو مركبة أو حيوان آلي، ثم يبرمجه ويختبره، وبعد الضغط على «أنا جاهز» ينتقل هو وبناؤه إلى ساحة اللعب.

 احذفها مانريدها  اي لاعب مكمل يمديه ان يرحل للبدئ اللعب دون إنتضار هي مو سباق او غيرها هي ساحه يستمتع فيها او يقاتل فيها حر فيه مثلا انت سويت روبوت و صديقك سوة روبوت راح هجم عليك ضربك و ضربك و قتلك انت مع الروبوت تروح تعود الى مصنعك و اكو تأثيرات تكسير اجزاء روبوت و تفكيكها و تدمرها و اذا شخصيتك مالت roblox ماتت الروبوت يموت و كذا لان انت بعد رحت للساحه و تتحمل مسؤليه موتك هههههههههه

تمام، نحذف نظام انتظار اللاعبين والعدّ التنازلي بالكامل. الماب مو سباق ولا جولة جماعية؛ هو عالم مفتوح مستمر، وكل لاعب يقرر متى يطلع من مصنعه إلى الساحة.

نظام الانتقال الجديد
كل مصنع يعمل بشكل مستقل:

اللاعب ينهي بناءه أو يختبره.
يضغط بدء اللعب.
يتم حفظ المشروع.
تُنشأ نسخة من المشروع في الساحة.
ينتقل اللاعب إليها فوراً.
باقي اللاعبين يستمرون بالبناء أو الاختبار أو اللعب بدون أي انتظار.
إذا لاعب ثاني لم يجهز بعد، لا يتأثر أبداً. يقدر يكمل بناءه، وبعد عشر دقائق أو ساعة يضغط بدء اللعب ويلتحق بالساحة مباشرة.

4. سكربت توزيع المصانع
في:

text


ServerScriptService
أنشئ Script اسمه:

text


FactoryManager
ضع داخله:

lua


local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local factoriesFolder = workspace:WaitForChild("Factories")
local startBuildingEvent = ReplicatedStorage:WaitForChild("StartBuilding")

local playerFactories = {}

local function getFactorySpawn(factory)
	return factory:FindFirstChild("Spawn")
end

local function getAvailableFactory()
	for _, factory in ipairs(factoriesFolder:GetChildren()) do
		if factory:IsA("Model") and factory:GetAttribute("OwnerUserId") == nil then
			return factory
		end
	end

	return nil
end

local function movePlayerToPart(player, part)
	local character = player.Character

	if not character then
		player:LoadCharacter()
		character = player.Character or player.CharacterAdded:Wait()
	end

	local humanoidRootPart = character:WaitForChild("HumanoidRootPart")
	humanoidRootPart.CFrame = part.CFrame + Vector3.new(0, 4, 0)
end

startBuildingEvent.OnServerEvent:Connect(function(player)
	if playerFactories[player] then
		local currentFactory = playerFactories[player]
		local spawnPart = getFactorySpawn(currentFactory)

		if spawnPart then
			movePlayerToPart(player, spawnPart)
		end

		return
	end

	local factory = getAvailableFactory()

	if not factory then
		warn("لا يوجد مصنع متاح للاعب: " .. player.Name)
		return
	end

	factory:SetAttribute("OwnerUserId", player.UserId)
	factory:SetAttribute("OwnerName", player.Name)

	playerFactories[player] = factory

	local spawnPart = getFactorySpawn(factory)

	if spawnPart then
		movePlayerToPart(player, spawnPart)
	end

	print(player.Name .. " استلم " .. factory.Name)
end)

Players.PlayerRemoving:Connect(function(player)
	local factory = playerFactories[player]

	if factory then
		factory:SetAttribute("OwnerUserId", nil)
		factory:SetAttribute("OwnerName", nil)
		playerFactories[player] = nil
	end
end)

5. كود السيرفر لوضع البلوك
داخل ServerScriptService أنشئ Script اسمه:

text


BuildServer
ضع داخله:

lua


local ReplicatedStorage = game:GetService("ReplicatedStorage")

local placePartEvent = ReplicatedStorage:WaitForChild("PlacePart")
local factoriesFolder = workspace:WaitForChild("Factories")

local function getPlayerFactory(player)
	for _, factory in ipairs(factoriesFolder:GetChildren()) do
		if factory:GetAttribute("OwnerUserId") == player.UserId then
			return factory
		end
	end

	return nil
end

local function isPositionInsideBuildArea(position, buildArea)
	local localPosition = buildArea.CFrame:PointToObjectSpace(position)
	local halfSize = buildArea.Size / 2

	return math.abs(localPosition.X) <= halfSize.X
		and math.abs(localPosition.Z) <= halfSize.Z
		and math.abs(localPosition.Y) <= 10
end

placePartEvent.OnServerEvent:Connect(function(player, partType, position)
	if partType ~= "Block" then
		return
	end

	local factory = getPlayerFactory(player)

	if not factory then
		return
	end

	local buildArea = factory:FindFirstChild("BuildArea")
	local playerBuilds = factory:FindFirstChild("PlayerBuilds")

	if not buildArea or not playerBuilds then
		return
	end

	if not isPositionInsideBuildArea(position, buildArea) then
		warn(player.Name .. " حاول وضع قطعة خارج مصنعه")
		return
	end

	if #playerBuilds:GetChildren() >= 300 then
		warn(player.Name .. " وصل إلى الحد الأقصى للقطع")
		return
	end

	local newBlock = Instance.new("Part")
	newBlock.Name = "Block"
	newBlock.Size = Vector3.new(4, 4, 4)
	newBlock.Position = Vector3.new(
		math.floor(position.X / 4 + 0.5) * 4,
		math.floor(position.Y / 4 + 0.5) * 4,
		math.floor(position.Z / 4 + 0.5) * 4
	)

	newBlock.Anchored = true
	newBlock.Material = Enum.Material.Plastic
	newBlock.Color = Color3.fromRGB(120, 170, 255)
	newBlock.Parent = playerBuilds
end)
ماذا يفعل هذا الكود؟
يتأكد أن اللاعب يملك مصنعاً.
يتأكد أن المكان داخل BuildArea.
يمنع وضع البلوك في مصنع لاعب آخر.
يحدد أقصى عدد للقطع.
يجعل البلوك ثابتاً.
يرتب البلوكات على شبكة مقدارها 4 Studs.
يجعل السيرفر هو الذي ينشئ البلوك، وليس اللاعب.
هذه النقطة مهمة جداً: لا تجعل العميل ينشئ القطع بنفسه، لأن اللاعب يستطيع استغلال ذلك وتخريب اللعبة.

		return

		return

7. اختبار المرحلة
اختبر هذه الحالات:

اللاعب يضغط البناء.
يختار بلوك.
يضع البلوك داخل مصنعه.

تحديد القطعة عند لمسها.

تحتاج تطوير و تصحيح البناء مو سلس اوصحيح من ابني لازم اضغط اكثر من ضغطه حتى اكدر ابني و مااقدر ابني على بلوكه 2 مثلا احط بلوكه و ابني فوقها او يمينها او يسارها او تحتها و مااقدر ابني بعد فوق و اول بلوكه احطها على الارض جزئها السفلي دخل تحت الارض و جزئها العلوي طالع فوق مثل الارض بلعت نصها و كذا اذا فهمتني وحسن طريقه البناء 

إي فهمتك. المشكلة من طريقتنا القديمة: كنا نأخذ mouse.Hit.Position مباشرة، لذلك:

البلوك يطلع نصفه داخل الأرض.
ما يعرف هل تريد البناء فوق البلوك أو بجانبه.
أحياناً الضغط لا يُلتقط بسبب واجهة المستخدم.
لا يوجد Preview يوضح مكان البلوك قبل وضعه.
الضغط على بلوك موجود لا يحدد الوجه المطلوب.
نحتاج نغير نظام البناء إلى Face Snapping + Preview، مثل أنظمة البناء الاحترافية.

1. تعديل BuildClient
استبدل كود البناء القديم داخل BuildClient بهذا:

lua


local Players = game:GetService("Players")
local UserInputService = game:GetService("UserInputService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")

local player = Players.LocalPlayer
local camera = workspace.CurrentCamera

local gui = script.Parent
local selectedTool = gui:WaitForChild("SelectedTool")

local placePartEvent = ReplicatedStorage:WaitForChild("PlacePart")
local deletePartEvent = ReplicatedStorage:WaitForChild("DeletePart")

local GRID_SIZE = 4
local BLOCK_SIZE = Vector3.new(4, 4, 4)

local previewBlock = Instance.new("Part")
previewBlock.Name = "BuildPreview"
previewBlock.Size = BLOCK_SIZE
previewBlock.Anchored = true
previewBlock.CanCollide = false
previewBlock.CanTouch = false
previewBlock.CanQuery = false
previewBlock.Transparency = 0.5
previewBlock.Material = Enum.Material.ForceField
previewBlock.Color = Color3.fromRGB(0, 255, 100)
previewBlock.Parent = workspace

local currentPosition = nil
local currentTarget = nil
local currentNormal = nil

local function snap(value)
	return math.floor((value / GRID_SIZE) + 0.5) * GRID_SIZE
end

local function snapPosition(position)
	return Vector3.new(
		snap(position.X),
		snap(position.Y),
		snap(position.Z)
	)
end

local function getMouseRaycast()
	local mouseLocation = UserInputService:GetMouseLocation()

	local ray = camera:ViewportPointToRay(
		mouseLocation.X,
		mouseLocation.Y
	)

	local raycastParams = RaycastParams.new()
	raycastParams.FilterType = Enum.RaycastFilterType.Exclude
	raycastParams.FilterDescendantsInstances = {
		player.Character,
		previewBlock
	}

	return workspace:Raycast(ray.Origin, ray.Direction * 1000, raycastParams)
end

local function getBuildPosition(result)
	local target = result.Instance
	local normal = result.Normal
	local hitPosition = result.Position

	-- إذا لمسنا أرضية البناء
	if target.Name == "BuildArea" then
		return Vector3.new(
			snap(hitPosition.X),
			target.Position.Y + target.Size.Y / 2 + BLOCK_SIZE.Y / 2,
			snap(hitPosition.Z)
	)
	end

	-- إذا لمسنا بلوكاً أو قطعة بناء
	local position = hitPosition + Vector3.new(
		normal.X * BLOCK_SIZE.X / 2,
		normal.Y * BLOCK_SIZE.Y / 2,
		normal.Z * BLOCK_SIZE.Z / 2
	)

	return snapPosition(position)
end

RunService.RenderStepped:Connect(function()
	if selectedTool.Value ~= "Block" then
		previewBlock.Transparency = 1
		currentPosition = nil
		currentTarget = nil
		currentNormal = nil
		return
	end

	local result = getMouseRaycast()

	if not result then
		previewBlock.Transparency = 1
		currentPosition = nil
		return
	end

	local buildPosition = getBuildPosition(result)

	currentPosition = buildPosition
	currentTarget = result.Instance
	currentNormal = result.Normal

	previewBlock.Position = buildPosition
	previewBlock.Transparency = 0.5
end)

UserInputService.InputBegan:Connect(function(input, gameProcessed)
	if gameProcessed then
		return
	end

	if input.UserInputType ~= Enum.UserInputType.MouseButton1 then
		return
	end

	if selectedTool.Value == "Block" then
		if currentPosition then
			placePartEvent:FireServer(
				"Block",
				currentPosition,
				currentTarget,
				currentNormal
			)
		end

	elseif selectedTool.Value == "Delete" then
		local result = getMouseRaycast()

		if result then
			deletePartEvent:FireServer(result.Instance)
		end
	end
end)

2. تعديل كود السيرفر
استبدل حدث PlacePart القديم بهذا الجزء:

lua


local ReplicatedStorage = game:GetService("ReplicatedStorage")

local placePartEvent = ReplicatedStorage:WaitForChild("PlacePart")
local factoriesFolder = workspace:WaitForChild("Factories")

local GRID_SIZE = 4
local BLOCK_SIZE = Vector3.new(4, 4, 4)
local MAX_PARTS = 300

local function getPlayerFactory(player)
	for _, factory in ipairs(factoriesFolder:GetChildren()) do
		if factory:GetAttribute("OwnerUserId") == player.UserId then
			return factory
		end
	end

	return nil
end

local function isPositionInsideBuildArea(position, buildArea)
	local localPosition = buildArea.CFrame:PointToObjectSpace(position)
	local halfSize = buildArea.Size / 2

	return math.abs(localPosition.X) <= halfSize.X
		and math.abs(localPosition.Z) <= halfSize.Z
		and localPosition.Y >= -2
		and localPosition.Y <= 200
end

local function snap(value)
	return math.floor((value / GRID_SIZE) + 0.5) * GRID_SIZE
end

local function snapPosition(position)
	return Vector3.new(
		snap(position.X),
		snap(position.Y),
		snap(position.Z)
	)
end

local function isValidNumber(value)
	return typeof(value) == "number"
		and value == value
		and math.abs(value) < 10000
end

placePartEvent.OnServerEvent:Connect(function(
	player,
	partType,
	position,
	target,
	normal
)
	if partType ~= "Block" then
		return
	end

	if typeof(position) ~= "Vector3" then
		return
	end

	if typeof(normal) ~= "Vector3" then
		return
	end

	if not isValidNumber(position.X)
		or not isValidNumber(position.Y)
		or not isValidNumber(position.Z) then
		return
	end

	local factory = getPlayerFactory(player)

	if not factory then
		return
	end

	local buildArea = factory:FindFirstChild("BuildArea")
	local playerBuilds = factory:FindFirstChild("PlayerBuilds")

	if not buildArea or not playerBuilds then
		return
	end

	if #playerBuilds:GetChildren() >= MAX_PARTS then
		return
	end

	local finalPosition = snapPosition(position)

	if not isPositionInsideBuildArea(finalPosition, buildArea) then
		return
	end

	-- التأكد أن الهدف تابع لمصنع اللاعب
	if target and target:IsDescendantOf(factory) then
		local targetBelongsToPlayerBuilds =
			target:IsDescendantOf(playerBuilds)

		if not targetBelongsToPlayerBuilds
			and target.Name ~= "BuildArea" then
			return
		end
	end

	local newBlock = Instance.new("Part")

	newBlock.Name = "Block"
	newBlock.Size = BLOCK_SIZE
	newBlock.Position = finalPosition
	newBlock.Anchored = true
	newBlock.CanCollide = true
	newBlock.Material = Enum.Material.Plastic
	newBlock.Color = Color3.fromRGB(120, 170, 255)

	newBlock:SetAttribute("OwnerUserId", player.UserId)
	newBlock:SetAttribute("ObjectType", "BuildPart")

	newBlock.Parent = playerBuilds
end)
فائدة التحقق في السيرفر
حتى لو اللاعب غيّر الكود من عنده، السيرفر يتأكد من:

أن المكان داخل مصنعه.
أن القطعة ليست خارج الحدود.
أن عدد القطع لم يتجاوز الحد.
أن القطعة المستهدفة تابعة لمشروعه.
أن الإحداثيات ليست غريبة.
أن اللاعب لا يبني في مصنع شخص آخر.
3. إصلاح مشكلة دخول البلوك داخل الأرض
سبب دخول البلوك داخل الأرض أن الكود القديم كان يستخدم مكان الضربة نفسه:

lua


mouse.Hit.Position
لكن مكان الضربة يكون على سطح الأرض، بينما مركز البلوك يجب أن يكون أعلى من السطح بنصف ارتفاعه:

lua


buildArea.Position.Y
+ buildArea.Size.Y / 2
+ BLOCK_SIZE.Y / 2
في الكود الجديد استخدمنا:

lua


target.Position.Y + target.Size.Y / 2 + BLOCK_SIZE.Y / 2
لذلك إذا كانت الأرض على ارتفاع Y = 0، وحجمها العمودي 1، فمركز البلوك يصبح تقريباً:

text


Y = 0.5 + 2
Y = 2.5
وبالتالي أسفل البلوك يكون على سطح الأرض بالضبط.

4. اجعل الأرض لا تمنع المؤشر

text

إذا جعلت:

text

فالـ Raycast لن يراها، ولن يعرف اللاعب مكان البناء.

lua


normal = Vector3.new(1, 0, 0)

6. ملاحظة عن البناء تحت البلوك
البناء تحت البلوك مسموح فقط إذا كانت هناك مساحة، لكن لا تسمح بوضع البلوك داخل الأرض. لاحقاً نضيف فحصاً يمنع:

وضع بلوكين في نفس المكان.
وضع بلوك داخل بلوك.
البناء تحت مستوى الأرض.
البناء خارج حدود المصنع.
بعد تطبيق هذا التعديل، يصير البناء مثل ألعاب البناء الحقيقية: تحرك الماوس، تشاهد مكان البلوك الشفاف، تضغط مرة واحدة، والقطعة تلتصق بالسطح الصحيح بدون دخول داخل الأرض 

الفكرة واضحة. تريد تسوي ماب يشبه Sandbox / Roblox Studio مصغّر داخل روبلوكس، بحيث اللاعب:
يحصل على غرفة خاصة وآمنة للبناء.
يبني روبوتات، سيارات، طائرات، صواريخ وأي شيء يريده.
يبرمج الأشياء بأكواد حقيقية، أو يستخدم أكواد جاهزة للمبتدئين.
يحدد الإحداثيات بنفسه حتى يضع القطع بمكان دقيق.
ينشئ أزرار وواجهة GUI خاصة به للتحكم بالبناء.
يقدر يربط زرًا بأحداث، مثل إطلاق صاروخ أو تحريك روبوت.
يدعم الكمبيوتر والجوال، مثل الضغط المطوّل على زر أو لمس الشاشة.
يمنع تخريب غرف اللاعبين الآخرين أو العالم العام.
يحتوي على زر لتأكيد انتهاء البناء، ثم زر لبدء اللعب والتجربة.
والأفضل ننفذها على مراحل، لأن بناء Roblox Studio كامل داخل ماب واحد مشروع ضخم:
نظام الغرف الخاصة وحماية البناء.
نظام وضع وتحريك وحذف البلوكات مع الإحداثيات.
نظام حفظ وتحميل بناء اللاعب.
نظام البرمجة بالأكواد، مع Sandbox آمن يمنع الأكواد التخريبية.
أكواد جاهزة للمبتدئين.
نظام GUI مخصص يصممه اللاعب.
ربط الأزرار بالأشياء والأحداث.
وضع التجربة واللعب داخل الغرفة.
نظام النشر أو مشاركة البناء بشكل آمن، إذا أردت إضافته لاحقًا.
ملاحظة مهمة: اللاعب لا يمكنه تشغيل أكواد Luau حقيقية مباشرة داخل السيرفر باستخدام loadstring؛ لأن هذا يسبب خطورة كبيرة على الماب. لذلك سنسوي لغة أوامر خاصة وآمنة تشبه البرمجة الحقيقية، مثل:
lua
Block.Place("Part", Vector3.new(5, 2, 0))
Robot.Move(Vector3.new(0, 0, 10))
Button.OnPressed(function()
Rocket.Launch()
end)
لكن اللعبة هي التي تفسر هذه الأوامر وتسمح فقط بالأشياء المصرح بها، مثل البناء والتحريك والتفاعل، بدون الوصول إلى خدمات السيرفر أو تخريب ممتلكات اللاعبين.
نبدأ أولًا بتصميم هيكل الماب ونظام الغرف، وبعدها نبرمج وضع البلوكات والإحداثيات، ثم نضيف نظام البرمجة والـGUI تدريجيًا.
ايييييي المهم انت شفت اخر كود حصلته؟ مالت البلوكه تكون تحت الارض و كذا اخذت الكود جديد ولقيت نفسي مااقدر احط بلوكات يعني خربان الكود مو شغال و بعدها نكمل المرحلة التالية بعد نجاح هذا النظام يعني المرحله التاليه من كودات و برمجه
فتحت المستند، لكن الموجود فيه حاليًا هو شرح فكرة الماب فقط، وما ظهر عندي آخر كود نظام وضع البلوكة تحت الأرض ولا كود النسخة الجديدة التي صار بعدها ما تقدر تحط بلوكات.
حتى أصلحه بدقة، أرسل هنا:
الـ LocalScript المسؤول عن وضع البلوكة.
الـ Script الموجود في ServerScriptService إن وجد.
الـ RemoteEvent ومكانه داخل Explorer.
صورة أو نص الخطأ الذي يظهر في Output باللون الأحمر.

local ReplicatedStorage = game:GetService("ReplicatedStorage")

local placePartEvent = ReplicatedStorage:WaitForChild("PlacePart")
local factoriesFolder = workspace:WaitForChild("Factories")

local GRID_SIZE = 4
local BLOCK_SIZE = Vector3.new(4, 4, 4)
local MAX_PARTS = 300

local function getPlayerFactory(player)
	for _, factory in ipairs(factoriesFolder:GetChildren()) do
		if factory:GetAttribute("OwnerUserId") == player.UserId then
			return factory
		end
	end

	return nil
end

local function isPositionInsideBuildArea(position, buildArea)
	local localPosition = buildArea.CFrame:PointToObjectSpace(position)
	local halfSize = buildArea.Size / 2

	return math.abs(localPosition.X) <= halfSize.X
		and math.abs(localPosition.Z) <= halfSize.Z
		and localPosition.Y >= -2
		and localPosition.Y <= 200
end

local function snap(value)
	return math.floor((value / GRID_SIZE) + 0.5) * GRID_SIZE
end

local function snapPosition(position)
	return Vector3.new(
		snap(position.X),
		snap(position.Y),
		snap(position.Z)
	)
end

local function isValidNumber(value)
	return typeof(value) == "number"
		and value == value
		and math.abs(value) < 10000
end

placePartEvent.OnServerEvent:Connect(function(
	player,
	partType,
	position,
	target,
	normal
)
	if partType ~= "Block" then
		return
	end

	if typeof(position) ~= "Vector3" then
		return
	end

	if typeof(normal) ~= "Vector3" then
		return
	end

	if not isValidNumber(position.X)
		or not isValidNumber(position.Y)
		or not isValidNumber(position.Z) then
		return
	end

	local factory = getPlayerFactory(player)

	if not factory then
		return
	end

	local buildArea = factory:FindFirstChild("BuildArea")
	local playerBuilds = factory:FindFirstChild("PlayerBuilds")

	if not buildArea or not playerBuilds then
		return
	end

	if #playerBuilds:GetChildren() >= MAX_PARTS then
		return
	end

	local finalPosition = snapPosition(position)

	if not isPositionInsideBuildArea(finalPosition, buildArea) then
		return
	end

	-- التأكد أن الهدف تابع لمصنع اللاعب
	if target and target:IsDescendantOf(factory) then
		local targetBelongsToPlayerBuilds =
			target:IsDescendantOf(playerBuilds)

		if not targetBelongsToPlayerBuilds
			and target.Name ~= "BuildArea" then
			return
		end
	end

	local newBlock = Instance.new("Part")

	newBlock.Name = "Block"
	newBlock.Size = BLOCK_SIZE
	newBlock.Position = finalPosition
	newBlock.Anchored = true
	newBlock.CanCollide = true
	newBlock.Material = Enum.Material.Plastic
	newBlock.Color = Color3.fromRGB(120, 170, 255)

	newBlock:SetAttribute("OwnerUserId", player.UserId)
	newBlock:SetAttribute("ObjectType", "BuildPart")

	newBlock.Parent = playerBuilds
end

local currentTarget = nil
local currentNormal = nil

local function snap(value)
	return math.floor((value / GRID_SIZE) + 0.5) * GRID_SIZE
end

local function snapPosition(position)
	return Vector3.new(
		snap(position.X),
		snap(position.Y),
		snap(position.Z)
	)
end

local function getMouseRaycast()
	local mouseLocation = UserInputService:GetMouseLocation()

	local ray = camera:ViewportPointToRay(
		mouseLocation.X,
		mouseLocation.Y
	)

	local raycastParams = RaycastParams.new()
	raycastParams.FilterType = Enum.RaycastFilterType.Exclude
	raycastParams.FilterDescendantsInstances = {
		player.Character,
		previewBlock
	}

	return workspace:Raycast(ray.Origin, ray.Direction * 1000, raycastParams)
end

local function getBuildPosition(result)
	local target = result.Instance
	local normal = result.Normal
	local hitPosition = result.Position

	-- إذا لمسنا أرضية البناء
	if target.Name == "BuildArea" then
		return Vector3.new(
			snap(hitPosition.X),
			target.Position.Y + target.Size.Y / 2 + BLOCK_SIZE.Y / 2,
			snap(hitPosition.Z)
	)
	end

	-- إذا لمسنا بلوكاً أو قطعة بناء
	local position = hitPosition + Vector3.new(
		normal.X * BLOCK_SIZE.X / 2,
		normal.Y * BLOCK_SIZE.Y / 2,
		normal.Z * BLOCK_SIZE.Z / 2
	)

	return snapPosition(position)
end

RunService.RenderStepped:Connect(function()
	if selectedTool.Value ~= "Block" then
		previewBlock.Transparency = 1
		currentPosition = nil
		currentTarget = nil
		currentNormal = nil
		return
	end

	local result = getMouseRaycast()

	if not result then
		previewBlock.Transparency = 1
		currentPosition = nil
		return
	end

	local buildPosition = getBuildPosition(result)

	currentPosition = buildPosition
	currentTarget = result.Instance
	currentNormal = result.Normal

	previewBlock.Position = buildPosition
	previewBlock.Transparency = 0.5
end)

UserInputService.InputBegan:Connect(function(input, gameProcessed)
	if gameProcessed then
		return
	end

	if input.UserInputType ~= Enum.UserInputType.MouseButton1 then
		return
	end

	if selectedTool.Value == "Block" then
		if currentPosition then
			placePartEvent:FireServer(
				"Block",
				currentPosition,
				currentTarget,
				currentNormal
			)
		end

	elseif selectedTool.Value == "Delete" then
		local result = getMouseRaycast()

		if result then
			deletePartEvent:FireServer(result.Instance)
		end
	end
end)

	local factory = getPlayerFactory()
	if not factory then
		previewBlock.Transparency = 1
		currentPosition = nil
		currentTarget = nil
		currentNormal = nil
		return
	end
	if selectedTool.Value ~= "Block" then
		previewBlock.Transparency = 1
		currentPosition = nil
		currentTarget = nil
		currentNormal = nil
		return
	end

	if not result then
		previewBlock.Transparency = 1
		currentPosition = nil
		currentTarget = nil
		currentNormal = nil
		return
	end

	currentPosition = buildPosition
	currentTarget = result.Instance
	currentNormal = result.Normal
	previewBlock.Position = buildPosition
	previewBlock.Transparency = 0.5
end)

lua
local deletePartEvent = ReplicatedStorage:WaitForChild("DeletePart")
deletePartEvent.OnServerEvent:Connect(function(player, target)
	if not target or not target:IsA("BasePart") then
		return
	end
	local factory = getPlayerFactory(player)
	if not factory then
		return
	end
	local playerBuilds = factory:FindFirstChild("PlayerBuilds")
	if not playerBuilds then
		return
	end
	-- السماح بحذف بلوكات اللاعب فقط
	if not target:IsDescendantOf(playerBuilds) then
		return
	end
	-- التأكد أن القطعة من نوع بناء
	if target:GetAttribute("OwnerUserId") ~= player.UserId then
		return
	end
	if target:GetAttribute("ObjectType") ~= "BuildPart" then
		return
	end
	target:Destroy()
end)

local movePartEvent = ReplicatedStorage:WaitForChild("MovePart")
local function moveSelectedBlock(offset, rotation)
	if not selectedBlock then
		return
	end
	if not selectedBlock:IsDescendantOf(workspace) then
		selectedBlock = nil
		highlight.Enabled = false
		return
	end
	local newPosition = selectedBlock.Position + offset
	local newRotation = selectedBlock.Orientation + rotation
	movePartEvent:FireServer(
		selectedBlock,
		newPosition,
		newRotation
	)
end

4. أضف كود السيرفر للتحريك
في نهاية BuildingServer أضف:
lua
local movePartEvent = ReplicatedStorage:WaitForChild("MovePart")
movePartEvent.OnServerEvent:Connect(function(
	player,
	target,
	newPosition,
	newRotation
)
	if not target or not target:IsA("BasePart") then
		return
	end
	if typeof(newPosition) ~= "Vector3" then
		return
	end
	if typeof(newRotation) ~= "Vector3" then
		return
	end
	local factory = getPlayerFactory(player)
	if not factory then
		return
	end
	local buildArea = factory:FindFirstChild("BuildArea")
	local playerBuilds = factory:FindFirstChild("PlayerBuilds")
	if not buildArea or not playerBuilds then
		return
	end
	if not target:IsDescendantOf(playerBuilds) then
		return
	end
	if target:GetAttribute("OwnerUserId") ~= player.UserId then
		return
	end
	if target:GetAttribute("ObjectType") ~= "BuildPart" then
		return
	end
	if not isPositionInsideBuildArea(newPosition, buildArea) then
		return
	end
	local finalPosition = Vector3.new(
		snap(newPosition.X),
		newPosition.Y,
		snap(newPosition.Z)
	)
	target.Position = finalPosition
	target.Orientation = newRotation
end)

6. ملاحظة مهمة
حاليًا عند تحريك البلوكة، السيرفر يتحقق من أن مركزها داخل BuildArea. هذا يمنع نقلها خارج مصنعك، لكنه لا يتحقق بعد من تداخلها مع بلوكة ثانية. سنضيف منع التداخل في الحزمة التالية مع:

اختبر الآن وضع التحديد والتحريك والتدوير. إذا اشتغلت كلها، ننتقل دفعة واحدة إلى منع التداخل + حفظ وتحميل البناء.
موشغاله مالت اعلى و اسفل و غيرها و القائمه مو متطورة و تحريكات مو شغاله ليش؟ لان مابيه تحريكات الاسهم او دائرة ليش؟ لان ماكو شي متطور كلها كلاسيكِ سيء و مو شغال

ماكو دائرة تدوير.

الخطأ واضح:
text
X cannot be assigned to
Y cannot be assigned to
Z cannot be assigned to
في Roblox لا يمكنك تعديل قيمة Vector3.X أو Vector3.Y مباشرة، مثل:
lua
position.X = position.X + 4
لأن Vector3 غير قابل للتعديل بهذه الطريقة. لازم تنشئ Vector3 جديدًا.
أصلح كود BuildClient
في الأسطر القريبة من 278–288، ابحث عن أي كود يشبه:
lua
position.X = position.X + amount
position.Y = position.Y + amount
position.Z = position.Z + amount
أو:
lua
rotation.X = rotation.X + amount
size.Y = size.Y + amount
واستبدله بهذه الدوال:
lua
local function changeX(value, amount)
	return Vector3.new(
		value.X + amount,
		value.Y,
		value.Z
	)
end
local function changeY(value, amount)
	return Vector3.new(
		value.X,
		value.Y + amount,
		value.Z
	)
end
local function changeZ(value, amount)
	return Vector3.new(
		value.X,
		value.Y,
		value.Z + amount
	)
end
استخدمها هكذا
بدل:
lua
position.X = position.X + GRID_SIZE
اكتب:
lua
position = changeX(position, GRID_SIZE)
بدل:
lua
position.X = position.X - GRID_SIZE
اكتب:
lua
position = changeX(position, -GRID_SIZE)
وبالنسبة للمحور Y:
lua
position = changeY(position, GRID_SIZE)
position = changeY(position, -GRID_SIZE)
وبالنسبة للمحور Z:
lua
position = changeZ(position, GRID_SIZE)
position = changeZ(position, -GRID_SIZE)
التدوير
إذا كان عندك كود مثل:
lua
rotation.Y = rotation.Y + 90
استبدله بـ:
lua
rotation = Vector3.new(
	rotation.X,
	rotation.Y + 90,
	rotation.Z
)
وللتدوير على المحاور الأخرى:
lua
rotation = Vector3.new(
	rotation.X + 90,
	rotation.Y,
	rotation.Z
)
lua
rotation = Vector3.new(
	rotation.X,
	rotation.Y,
	rotation.Z + 90
)
التكبير والتصغير
بدل:
lua
size.X = size.X + 1
استخدم:
lua
size = Vector3.new(
	math.max(1, size.X + 1),
	size.Y,
	size.Z
)
وباقي المحاور:
lua
size = Vector3.new(
	size.X,
	math.max(1, size.Y + 1),
	size.Z
)
lua
size = Vector3.new(
	size.X,
	size.Y,
	math.max(1, size.Z + 1)
)
استخدام math.max(1, ...) يمنع جعل حجم البلوكة صفرًا أو قيمة سالبة.
تعديل مهم في أزرار الواجهة
إذا عندك دالة تحريك مثل:
lua
local function changePosition(axis, amount)
	local newPosition = selectedBlock.Position
	newPosition[axis] = newPosition[axis] + amount
end
فهذه هي سبب الخطأ؛ لا تستخدم:
lua
newPosition[axis] = ...
استبدل الدالة كاملة بهذه:
lua
local function changePosition(axis, amount)
	if not selectedBlock then
		return
	end
	local oldPosition = selectedBlock.Position
	local newPosition
	if axis == "X" then
		newPosition = Vector3.new(
			oldPosition.X + amount,
			oldPosition.Y,
			oldPosition.Z
		)
	elseif axis == "Y" then
		newPosition = Vector3.new(
			oldPosition.X,
			oldPosition.Y + amount,
			oldPosition.Z
		)
	elseif axis == "Z" then
		newPosition = Vector3.new(
			oldPosition.X,
			oldPosition.Y,
			oldPosition.Z + amount
		)
	else
		return
	end
	movePartEvent:FireServer(
		selectedBlock,
		newPosition,
		selectedBlock.Orientation
	)
end
ثم اربط الأزرار هكذا:
lua
xPlusButton.Activated:Connect(function()
	changePosition("X", GRID_SIZE)
end)
xMinusButton.Activated:Connect(function()
	changePosition("X", -GRID_SIZE)
end)
yPlusButton.Activated:Connect(function()
	changePosition("Y", GRID_SIZE)
end)
yMinusButton.Activated:Connect(function()
	changePosition("Y", -GRID_SIZE)
end)
zPlusButton.Activated:Connect(function()
	changePosition("Z", GRID_SIZE)
end)
zMinusButton.Activated:Connect(function()
	changePosition("Z", -GRID_SIZE)
end)
بعد هذا التعديل ستختفي أخطاء:
text
X cannot be assigned to
Y cannot be assigned to
Z cannot be assigned to
والسبب أن التعديل صار ينشئ Vector3 جديدًا بدل محاولة تعديل خصائص Vector3 مباشرة.
نفس  الشي
إذا ظهر نفس الخطأ، فهذا يعني أن الكود القديم الذي يعدّل X/Y/Z مباشرة ما زال موجودًا في BuildClient. لا أقدر أحدد السطر الصحيح من رقم الخطأ فقط، لأن محتوى سكربتك الحالي غير ظاهر عندي.
افتح:
text
StarterGui
→ BuildGui
→ BuildClient
وانسخ لي الأسطر من 250 إلى 300، خصوصًا الأسطر التي فيها:
lua
.X =
.Y =
.Z =
أو أرسل كود BuildClient كاملًا.
لا تضف تعديلات أخرى الآن؛ نحتاج نستبدل الجزء المسبب للخطأ نفسه. غالبًا عندك واحد من هذه الأسطر ما زال موجودًا:
lua
current.X = ...
position.X = ...
rotation.Y = ...
size.Z = ...
وكلها يجب تحويلها إلى Vector3.new(...). أرسل الجزء حول السطر 278 وسأرجع لك النسخة المصححة جاهزة للنسخ واللصق.
