هلا اني عندي موقع اريد انشره على NETLIFY  بس مشكله موقعي كبير و مساحته  فوق 100 و فيه ذكاء اصطناعي يعني كود يخص ذكاء اصطناعي بس ماضفت فيه مفتاح و مااعرف اين  اضيف مفتاح في مكان امن رغم عندي اكثر من مفتاح


إي تگدر تنشره على Netlify، وحتى إذا حجمه أكثر من 100 ميغابايت فالمشكلة الأساسية غالبًا مو حجم الموقع، وإنما مكان كود الذكاء الاصطناعي ومفتاح الـ API.

المهم جدًا: لا تضع المفتاح داخل كود الواجهة الأمامية مثل React أو HTML أو JavaScript الذي يصل إلى المتصفح؛ لأن أي شخص يقدر يفتحه من Developer Tools ويستخرج المفتاح.

وضع المفتاح داخل Environment Variables في Netlify.

افتح الموقع في Netlify.

2. أنشئ Netlify Function
ضع ملفًا مثل:

text


netlify/functions/ai.mjs
ومحتواه، كمثال:

javascript


export default async (request) => {
  try {
    const { message } = await request.json();

    if (!message) {
      return new Response(
        JSON.stringify({ error: "Message is required" }),
        {
          status: 400,
          headers: { "Content-Type": "application/json" }
        }
      );
    }

    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${process.env.OPENAI_API_KEY}`
      },
      body: JSON.stringify({
        model: "gpt-4o-mini",
        messages: [
          {
            role: "user",
            content: message
          }
        ]
      })
    });

    const data = await response.json();

    return new Response(JSON.stringify(data), {
      status: response.status,
      headers: { "Content-Type": "application/json" }
    });
  } catch (error) {
    return new Response(
      JSON.stringify({ error: "Server error" }),
      {
        status: 500,
        headers: { "Content-Type": "application/json" }
      }
    );
  }
};
يتم الوصول إلى المتغير داخل Function بهذا الشكل:

async function askAI(message) {
  const response = await fetch("/.netlify/functions/ai", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"

    body: JSON.stringify({ message })
  });

  return await response.json();
}

2. .gitignore يمنع الرفع الجديد فقط
إذا كان ملف .env موجودًا داخل .gitignore فهذا جيد، لكن إذا سبق أن أضفته إلى Git أو GitHub فلن يكفي وضعه في .gitignore. يجب إزالة الملف من التتبع:
